# Khanya Nathi website

The website for Fairheads Benefit Services' "Shine with us" social impact initiative. It is built and maintained by Launch Digital.

- **Staging:** https://khanyanathi.launchweb.co.za/
- **Live domain (not yet pointed):** khanyanathi.co.za, on xneelo
- **Stack:** WordPress · Breakdance · ACF PRO · Rank Math · WP Rocket · Gravity Forms · Solid Security · NinjaFirewall
- **Client contact:** Anthea Thorne (Marketing Manager). **IT / server:** Johan Marais

## What's in this repo
| Path | What |
|---|---|
| `docs/local-setup.md` | **Start here.** Run the site locally on your branch |
| `docs/dev-brief-pillar-pages.md` | The current build brief (ECD and Academic & Career redesign) |
| `docs/brief-template.md` | Template for writing future developer briefs |
| `wp-content/mu-plugins/khanyanathi-core.php` | Site-specific PHP. Turns on ACF Local JSON |
| `wp-content/acf-json/` | ACF field groups, post types and taxonomies, version-controlled |
| `.wp-env.json` | Local WordPress environment |

Breakdance layouts and content live in the **staging database**, not in Git. See `docs/local-setup.md`.
